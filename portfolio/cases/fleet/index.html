Case / Internal software / Fleet operations

Stop chasing fleet deadlines across spreadsheets

A logistics company kept every vehicle, insurance date, repair and fuel record in a shared spreadsheet. Expired papers were found by accident, usually at a roadside check.

We built one system: a register, cards, repairs, fuel, directories, reports and reminders, with roles and an audit trail. Fleet Desk below is a fictional rebuild of that idea and every module works.

Problem, solution, result

1

The problem

Replace a shared fleet spreadsheet with a system that never forgets an insurance, inspection or service date, and keeps a trace of every change.

2

What we built

Twelve connected modules on one database: registry, cards, deadlines, repairs, fuel, directories, notifications, reports, import and export, integrations, access and an audit log.

3

Result

All the data in one place instead of scattered copies. Deadlines are found by the system, not by memory.

Integrations, import and reminders

Fuel-card system

Refueling data is pulled on a schedule. A failed sync is logged and raises an alert to the administrators.

Spreadsheet in and out

The old file is imported with a report: what is fine, what imports with a warning, what is skipped and why. Any section can be exported back.

Reminders that do not repeat

A daily check applies ten rules and sends one reminder per event to a messenger, team chat or email. If a channel is down, the message waits for a retry.

How it works

  1. 1

    Import once

    The old spreadsheet is loaded into the register with a report of data problems, so nothing is silently lost.

  2. 2

    One register

    Vehicles, documents, service, repairs, fuel cards and history live in a single database with roles and departments.

  3. 3

    Daily check

    A scheduled job counts every deadline, sets the color status and finds what crossed a warning threshold.

  4. 4

    Right person, right time

    Reminders go to a messenger, team chat or email once per event, with a log of everything that was sent.

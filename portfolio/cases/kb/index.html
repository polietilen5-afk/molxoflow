Case study / AI assistant

An assistant that answers only from your own sources, and says so when it does not know

Support teams answer the same questions all day, and a generic chatbot invents facts. This agent reads the company's site, files and systems, answers strictly from them with a citation under every claim, and hands unclear questions to people.

  • Search plus language model

1

The problem

Answers live in a site, a price sheet, a policy file and the heads of a few people. Customers wait, staff repeat themselves, and chatbots that guess put wrong prices and terms in writing.

2

What we built

A knowledge agent that collects the company's sources, keeps them in sync, answers only from the fragments it found, cites each one, refuses when nothing fits and routes the case to a person. It runs on a local model on the company's server or on a cloud model.

3

The result

Repeated questions answered at any hour with a source behind every answer. Gaps in the knowledge become a visible to-do list, and a test set shows whether a change made answers better or worse.

How it works

Four steps from a source to a cited answer

  1. 1

    Collect

    Pages, files and system records are split into short fragments. Each source has an audience, a last-sync date and a schedule.

  2. 2

    Find

    A question is matched against fragments the asker is allowed to see. Weak matches are dropped before the model is asked anything.

  3. 3

    Answer

    The model may use only the fragments found. Every statement carries a citation, and with no fragment the answer is a plain "I do not know".

  4. 4

    Improve

    Unanswered questions, thumbs-down ratings and conflicts between sources become tasks. A test set checks that fixes did not break other answers.

Integrations and notifications

Instant alerts

Each request is stored first, then sent to the manager by email and messenger. Channels can be switched on and off by rule.

First reply and pre-qualification

An automatic reply confirms the request. An assistant can summarize it for the manager and flag what is missing, without quoting prices.

CRM handoff and consent

Requests can be passed on to a CRM. The consent text and its version are saved with every request.

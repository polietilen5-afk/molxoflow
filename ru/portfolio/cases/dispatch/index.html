Кейс / настольное приложение

Заявки из групповых чатов собираются в одну аккуратную таблицу

Диспетчер следит за десятками чатов, чтобы заметить тех, кому нужно доехать или отправить посылку. Приложение читает чаты за него, раскладывает каждую заявку по полям, сопоставляет с расписанием и ведёт журнал каждого решения.

  • Настольное приложение
  • Извлечение с помощью ИИ
  • Запасной разбор по шаблонам
  • Сопоставление с рейсами
  • База данных на компьютере

Проблема, решение, результат

1

Проблема

Заявки приходят свободным текстом в десятки чатов, с опечатками и сокращениями. Найти нужные и сверить их с расписанием значило часы прокрутки и копирования.

2

Что сделали

Настольное приложение следит за чатами, извлекает тип, маршрут, дату и объём языковой моделью (с запасным разбором по правилам) и оценивает каждую заявку относительно рейсов перевозчика.

3

Результат

Вместо часов прокрутки короткий список готовых совпадений. Одно место для всех заявок, уровень уверенности у каждой и шаблон ответа в один клик.

Как это работает

Четыре шага от строки в чате до ответа

  1. 1

    Чтение

    Приложение читает новые сообщения из личных чатов менеджера на этом же компьютере. С машины уходит только текст для извлечения.

  2. 2

    Извлечение

    Языковая модель возвращает тип, пункт отправления и назначения, дату и объём. Если она недоступна, подключается разбор по шаблонам.

  3. 3

    Сопоставление

    Названия городов приводятся к единому написанию и сравниваются с каждым активным рейсом: точное совпадение, соседний город или похожее написание, плюс тип услуги, дни рейса и свободные места.

  4. 4

    Ответ

    Менеджер видит уровень уверенности, выбирает рейс и получает готовый ответ. Автоматически ничего не отправляется.
